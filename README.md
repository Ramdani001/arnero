# Dr. Arnero Card Shop

Project React (Vite + Tailwind CSS) berisi komponen `DrArneroCardShop`.

## Cara Menjalankan

1. Install dependency:
   ```bash
   npm install
   ```

2. Jalankan mode development:
   ```bash
   npm run dev
   ```
   Lalu buka URL yang muncul di terminal (biasanya `http://localhost:5173`).

3. Build untuk production:
   ```bash
   npm run build
   ```
   Hasil build ada di folder `dist/`.

4. Preview hasil build:
   ```bash
   npm run preview
   ```

## Struktur Folder

```
dr-arnero-card-shop/
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
└── src/
    ├── main.jsx              # Entry point React
    ├── index.css             # Import Tailwind
    └── DrArneroCardShop.jsx  # Komponen utama (file asli kamu)
```
